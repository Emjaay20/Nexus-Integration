# Nexus release hardening — candidate, not deployed

Baseline `e6675a92351c083c74289acdb81336c17536f3c7`. Canonical deployment https://nexus-integration.aetherhost.app/. The former Vercel status is not a verdict on this deployment.

## Product boundaries

Prioritize the implemented Rust/Actix workspace and Go supplier engine. Public Studio accepts at most 25 MPNs per request and 20 global enrichment requests per minute across replicas; other public operations share 120 requests/min. These are conservative interim global limits, not distributed per-client fairness. Authenticated durable jobs keep their own existing limits. The database request-limit migration must be applied; a missing database fails closed. Supplier calls still need upstream daily quotas/circuit breakers and cache review.

Pause the legacy integration hub's provider writes, synthetic sync and automatic demo seeds. Existing records are retained and labelled historical. The new authenticated test-event recorder persists only fixture metadata, uses a user-scoped idempotency key, and never updates provider health or dispatches a webhook. It returns 201 only after persistence, 200 on identical replay and 409 on changed fixture. A shared demo cannot write. Legacy API-key clients, Shopify callbacks/webhooks, ERP dispatch and reset actions are temporarily disabled. **Do not deploy if live connectors are in use until maintenance is approved, credentials/records backed up and a provider migration/replay plan exists.** A prolonged 503 may cause provider retry exhaustion or subscription removal. This is containment, not completed integration support.

Do not automatically delete old synthetic records, migrate encryption keys or rewrite provider connections. Audit and securely rotate any old weak seeded API keys and plaintext credentials before re-enabling external connections. Require encrypted versioned token storage, OAuth state bound to user/shop/expiry, provider signature checks, durable queue/outbox, idempotency, fixed provider origins or tested DNS/egress controls, redacted logs and provider sandbox acceptance. The new docs support endpoint is deterministic, not AI. The existing Rust sourcing brief is separate and retains its evidence-grounded model option.
